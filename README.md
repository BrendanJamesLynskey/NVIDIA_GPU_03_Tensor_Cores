# Tensor Cores — Five Generations of NVIDIA Matmul Hardware

A deep dive into NVIDIA's tensor cores from Volta (2017) to Blackwell (2024) — what hardware shapes each generation supports, the FP16/BF16/TF32/INT8/FP8/MX-FP4 number formats, structured sparsity, and the Transformer Engine. Includes an interactive precision-throughput calculator across every relevant data-center and consumer GPU.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_03_Tensor_Cores/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
